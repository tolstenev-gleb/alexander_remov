# Задачи

> Все задачи с вводом данных должны иметь защиту от некорректного ввода.

---

### Задача 1

Напишите программу для вычиления площади прямоугольника.

Пример ввода:
```bash
Enter the a: 2  
Enter the b: 3
```

Пример вывода:
```bash
The square of rectangle: 6
```

---

### Задача 2

Напишите программу для вычиления круга

Пример ввода:
```bash
Enter the radius: 2  
```

Пример вывода:
```bash
The square of circle: 12.560000
```

---

### Задача 3

Напишите программу, которая запрашивает три числа: `start`, `stop`, `step` и выводит все числа от `start` до `stop` с шагом `step`.

Пример ввода:
```bash
start: 10
stop: 30
stop: 5
```

Пример вывода:
```bash
10 15 20 25 30
```

---

### Задача 4

Напишите программу, которая запрашивает целое число и определяет, положительное оно, отрицательное или равно нулю.

Пример:
```bash
Enter a number: -5
The number is negative.
```
```bash
Enter a number: 5
The number is positive.
```

Отдельно обратайте ноль

---

### Задача 5

Напишите программу, которая запрашивает два целых числа и выводит большее из них. Если числа равны — сообщить об этом.

Пример ввода:
```bash
Enter first number: 10
Enter second number: 7
```

Пример вывода:
```bash
Max = 10
```
